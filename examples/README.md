# Examples

These examples describe workflows rather than bundling real saves or logs.

- `example-profile-export.md`: how to export Workshop and mod lists from a hosted profile.
- `example-troubleshooting-flow.md`: conservative order of operations for Workshop redownload failures.
- `example-quick-diagnosis.md`: what the high-level diagnosis flow is for.

Do not publish private saves, Steam IDs, usernames, or logs without reviewing them first.

Files matching `*.local.*` and `examples/exports/` are ignored by git.
