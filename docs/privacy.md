# Privacy And Support Bundles

Toolkit output can include local information from your Project Zomboid setup. Review anything you paste into a GitHub issue, forum post, Discord message, or support request.

## Data That May Appear

- Windows usernames in local paths.
- Hosted profile names and server public names.
- Steam usernames or Steam IDs from `players.db`.
- Player coordinates and alive/dead state.
- Workshop IDs and mod lists.
- Local Steam library paths.
- Server settings, including IDs generated by Project Zomboid.
- Log excerpts with file paths, mod names, errors, or process details.
- Toolkit action history under `logs/toolkit-actions.jsonl`, including local username, machine name, profile name, backup ZIP path, and action timestamps.
- Auto-backup inspection cache under `cache/auto-backups/`, including backup ZIP paths, hosted profile names, readme metadata, and ZIP content counts.

`logs/`, `cache/`, `backups/`, `exports/`, and `tmp/` are ignored by git in this repository. Still review them before copying the whole folder, compressing it, or sharing local support bundles manually.

## Before Opening An Issue

Remove or replace:

- your Windows username;
- Steam IDs if you do not want them public;
- private server names;
- private paths;
- IP addresses or connection details if present in logs;
- full save files or databases unless you intentionally want to share them.

Good redactions:

```text
C:\Users\<you>\Zomboid
SteamID=<redacted>
ProfileName=MyHostedServer
```

## Safer Issue Reports

Prefer short excerpts over full logs. Include:

- Project Zomboid version/build;
- Windows and PowerShell version;
- whether you are using in-game Host/co-op;
- the toolkit command you ran;
- whether Project Zomboid, Steam, Java, or mod helper tools were open;
- the smallest relevant error excerpt.

Do not upload valuable saves, `players.db`, or full exported profile folders unless you have reviewed them and are comfortable with the data they contain.
